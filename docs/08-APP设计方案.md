# 知芽学习机 APP — v1 设计方案

目标机型：小米 MIX 2（chiron），目标系统 LineageOS 22.x（Android 15，API 35）。
设计原则：**单 APP 即整个系统界面** + Device Owner 锁死，小孩无任何出口。

## 0. v1 范围（第一版只做这些）

- 打电话 / 收发短信（SIM 卡，儿童手表式白名单管控）
- 定位（家长可查，见 §3.1）
- 本机视频播放（指定文件夹）
- 文档查看（PDF / TXT / Markdown）
- 家长维护模式（隐藏入口 + 密码）

不做：浏览器、应用商店、任何联网娱乐功能、OTA（v1 手动装包）。

## 1. 总体架构

```
┌─────────────────────────────────────────┐
│  Zhiya Launcher（HOME，锁任务模式）       │
│  ┌──────┬──────┬──────┬──────┬────────┐  │
│  │ 电话 │ 短信 │ 定位 │ 视频 │ 文档   │  │  ← 小孩可见：5 个大图标
│  └──────┴──────┴──────┴──────┴────────┘  │
│  家长维护模式（隐藏手势 + 密码）            │
├─────────────────────────────────────────┤
│  Device Owner 策略层（见 docs/04）        │  ← 锁死：Home/状态栏/安全模式/恢复出厂/USB调试
├─────────────────────────────────────────┤
│  LineageOS 22.x（无 GMS）                │
└─────────────────────────────────────────┘
```

APP 本身声明 `CATEGORY.HOME` 成为桌面；Device Owner 把它设为锁任务包。
小孩看到的就是 5 个大色块图标，没有桌面、没有抽屉、没有设置入口。

## 2. 模块详细设计

### 2.1 电话模块（白名单拨号盘）

- 自研极简拨号盘：只显示白名单联系人（大头像 + 名字），点即拨打；不开放数字键盘（防乱拨）。
- 去电/来电双向白名单：非白名单来电自动挂断并记录；去电只能打给白名单。
- 实现：申请 `ROLE_DIALER` 成为默认电话应用，用 `InCallService` 接管通话界面，
  用 `CallScreeningService` 做来电拦截。比"调起系统拨号器"更彻底——系统拨号器里
  有通话记录、联系人等出口。
- 权限：`CALL_PHONE`、`READ_PHONE_STATE`、`READ_CALL_LOG`、`ANSWER_PHONE_CALLS`。
- 建议加：SOS 长按一键拨打家长（v1 可做，成本小）。

### 2.2 短信模块（默认短信应用 + 指令短信）

- 申请 `ROLE_SMS` 成为默认短信应用，自研收件箱：只显示白名单号码的短信，
  陌生号码短信静默存档（家长模式可见），不弹窗、不提醒。
- **指令短信**（核心设计，代替服务器）：
  - 家长手机发特定格式短信（如 `ZHIYA#LOC#口令`）→ APP 验证发件人在家长白名单
    且口令正确 → 自动回复一条含经纬度 + 地图链接的短信。
  - 指令集 v1：查定位（LOC）、响铃找手机（RING）、上报电量（BAT）。
  - 鉴权：家长号码白名单 + 口令，双重校验；指令短信不存入收件箱、不提醒小孩。
- 权限：`SEND_SMS`、`RECEIVE_SMS`、`READ_SMS`。

### 2.3 定位模块（无服务器）

- 定位源：`LocationManager`（GPS + Network）。LineageOS 无 GMS，
  没有 FusedLocationProvider——注意别引入 play-services-location 依赖。
  粗定位兜底：基站/ WiFi（`getCellLocation` 需 `READ_PHONE_STATE`）。
- 策略：平时不持续定位（省电），收到 LOC 指令时单次高精度定位后回复；
  可选定时上报（家长模式配置间隔，默认关闭）。
- 回复格式：`知芽定位 31.23,121.47 精度15m 电量82%` + 高德/百度地图链接
 （`https://uri.amap.com/marker?position=...` 纯链接，家长手机点开即看）。

### 2.4 视频模块（本机文件夹播放）

- 扫描固定目录（如 `/Zhiya/Video/`，家长模式可改），递归列出 mp4/mkv，
  列表显示缩略图 + 时长 + 断点续播进度。
- 播放器：Media3 ExoPlayer（Google 官方播放器库，API 成熟，软硬解自适应）。
- v1 不做：在线视频、投屏、倍速以外的花哨功能。倍速/选集可进 v2。

### 2.5 文档模块

- PDF：系统原生 `PdfRenderer`（无需第三方库，翻页+缩放够用）。
- TXT / Markdown：自渲染（TextView + 简单 md 解析，v1 只支持标题/列表/粗体）。
- 目录：`/Zhiya/Docs/`，按文件名列表。
- Office（doc/docx/ppt）v1 不做——解析重、版式乱；真有需求 v2 再接 POI。

### 2.6 家长维护模式

- 入口：连续点击屏幕角落 5 次（或音量键组合）→ 输密码。
- 通过后 `stopLockTask()`，可进行：管理白名单联系人、增删视频/文档、
  查看通话短信定位记录、配置上报间隔、检查更新。
- 退出维护模式自动恢复锁任务。

## 3. 关键技术决策

| # | 决策 | 推荐 | 备选 |
|---|---|---|---|
| 1 | 定位上报 | 短信指令式（无服务器、v1 零运维） | 自建服务器实时上报（v2 再议） |
| 2 | 拨号方案 | 自研拨号盘 + ROLE_DIALER 接管 | 调系统拨号器（有出口，不推荐） |
| 3 | 短信方案 | 自研收件箱 + ROLE_SMS 接管 | 只读短信（做不了指令回复，不推荐） |
| 4 | UI 技术栈 | Jetpack Compose（小孩 UI 色块大、圆角多，Compose 写起来快） | 传统 Views（你若更熟，可选） |
| 5 | 语言 | Kotlin（Android 官方首选，协程好用） | — |

minSdk 30 / targetSdk 35。包名建议 `com.zhiya.kiosk`（Device Owner 绑定用）。

## 4. 权限 / 系统角色清单

| 权限/角色 | 用途 | 申请时机 |
|---|---|---|
| Device Owner（`dpm set-device-owner`） | 锁任务、用户限制 | 刷机后首次开机，adb 一次 |
| `ROLE_DIALER` | 接管拨号 | 首次进电话模块引导 |
| `ROLE_SMS` | 接管短信 | 首次进短信模块引导 |
| 定位/通话/短信/电话状态 | 各模块功能 | 运行时动态申请 |
| `RECEIVE_BOOT_COMPLETED` | 开机自启进锁任务 | 安装时 |

## 5. 数据与文件规范

- 数据库（Room）：联系人白名单、通话记录、短信记录、定位记录、作息配置。
- 文件目录（内置存储根）：
  - `/Zhiya/Video/` — 视频
  - `/Zhiya/Docs/` — 文档
  - 家长模式支持 USB 拷入（维护模式下临时允许 MTP，不断 Device Owner 限制）。

## 6. 开源借鉴清单

| 项目 | 借鉴点 | 说明 |
|---|---|---|
| Headwind MDM（github.com/h-mdm，Apache 2.0） | kiosk/Device Owner 范式 | 开源 MDM，单应用 kiosk、设备策略、定位插件，v7 刚发布；**最值得通读** |
| Shelter（开源） | 工作资料隔离思想 | 用 Work Profile 做隔离，思路可借鉴到"小孩区/家长区"划分 |
| QKSMS（MPL 开源短信） | 短信应用结构 | 成为默认短信应用的完整实现参考 |
| Fossify Dialer（GPL） | 拨号盘 | 极简拨号实现参考 |
| mpv-android / VLC（GPL） | 播放器 | ExoPlayer 搞不定冷门编码时的兜底思路 |
| MuPDF（AGPL） | 文档渲染 | `PdfRenderer` 不够用时的升级路径（注意 AGPL 传染性） |

注意许可证：APP 本体建议 Apache 2.0/MIT；引用 AGPL（MuPDF）代码会传染，v1 用系统 `PdfRenderer` 避开。

## 7. 里程碑

- M1：壳 + Device Owner 锁死（5 个图标占位，Home/状态栏/安全模式无出口）
- M2：电话 + 短信（含白名单、拦截、指令短信鉴权）
- M3：定位（单次定位 + LOC/RING/BAT 指令）
- M4：视频 + 文档
- M5：家长维护模式 + 作息时间表
