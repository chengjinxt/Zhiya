# 自编译系统指南（AOSP / LineageOS）

## 路线建议

不要从纯 AOSP 起步（device tree 调试磨人），走 **fork LineageOS 官方包为底 + 改几处 + 重编译**：工作量从"几个月"降到"几个晚上"。

## 环境

- Linux（Ubuntu），`repo` 工具同步源码（约 250GB 磁盘），16GB+ 内存。
- 首次编译几小时，后续增量编译很快。

## 步骤

1. **拿 device tree**：从 LineageOS GitHub clone 对应机型的 device tree + kernel 源码。
2. **提取 blob**：用官方线刷包跑 `extract-files.sh`，把闭源驱动抽出来。
3. **编译**：`lunch` 选机型代号，`m` 开编，产物在 `out/` 目录（system.img 等）。
4. **烧录**：fastboot 逐分区刷入，或打包成线刷包（见 `flashing/`）。

## 定制点（学习机）

| 定制 | 做法 | 产物落点 |
|---|---|---|
| 换第一屏 logo | 重打包 splash/logo 分区镜像 | `flashing/splash/` |
| 换开机动画 | 替换 `bootanimation.zip`（PNG 序列 zip） | `system/prebuilt/` |
| 预装学习机 APP | 做到 system 分区，变卸不掉的系统应用 | `system/prebuilt/` |
| 默认 Device Owner | 编译期预置设备管理员策略 / 首次开机脚本 | `system/build-scripts/` |
| 砍功能 | 去掉电话、短信等不需要的系统应用 | device tree / 编译配置 |
| 改系统字符串 | frameworks/base 资源覆盖 | `system/` |

## 产物归档

每次编译产物按版本归档到 `releases/`，命名如 `zhiya-os-v0.1.0-oneplus8-20261016/`，保留可复现的编译记录（device tree commit + blob 版本）。
