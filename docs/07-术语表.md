# 术语表（英中对照 + 音标 + 文中含义）

**Binder** — /ˈbaɪndər/ — 原意"装订机、黏合剂"；文中含义：Android 进程间通信机制，APP 调系统 API 时通过 Binder 驱动把调用从 APP 进程传递到 system_server 进程。类比 Windows 的 RPC/LPC。

**ptrace** — /ˌpiːˈtreɪs/ — process trace 缩写，"进程跟踪"；文中含义：Linux 系统调用，调试器（gdb）靠它 attach 到目标进程读写内存/寄存器。只有相同 UID 的进程才能 ptrace 对方，是 UID 沙箱起作用的实例。

**untrusted_app** — /ʌnˈtrʌstɪd æp/ — "不受信任的应用"；文中含义：SELinux 策略中给普通第三方 APP 划分的安全域（domain）。UID 隔离之外的第二道墙：同处该域的进程能做什么被策略统一限制（如不能直接读裸块设备）。

**isolated** — /ˈaɪsəleɪtɪd/ — "被隔离的"（isolate 的形容词形态）；文中含义：`isolatedProcess="true"` 的 Service 跑在"隔离进程"里，每次启动分配全新一次性 UID，连自己 APP 的数据目录都访问不了。WebView 渲染进程、广告 SDK 常用。

**kiosk** — /ˈkiːɒsk/（美音亦读 /ˈkiːɑːsk/）— 原意"街头售货亭、报刊亭"；文中含义：IT 语境指"单用途自助终端"。kiosk 应用 = 独占整台设备的单用途应用；kiosk mode = 设备被锁定只能运行指定应用的模式。

**Corporate** — /ˈkɔːrpərət/ — "公司的、企业法人的"（corporation 的形容词）；文中含义：Corporate-Owned = "企业所有的"。COSU 场景即公司批量采购设备、只装指定应用发给员工/客户。

**appId** — /ˌæp aɪˈdiː/ — "应用编号"；文中含义：PackageManager 给每个安装包分配的序号（10000 起），与 userId 拼出最终 Linux UID：`UID = userId × 100000 + appId`。

## 缩略词

- ROM — Read Only Memory — 只读存储器（刷机语境中指系统镜像包）
- AOSP — Android Open Source Project — 安卓开源项目
- HAL — Hardware Abstraction Layer — 硬件抽象层
- GSI — Generic System Image — 通用系统镜像
- AVB — Android Verified Boot — 安卓验证启动
- GMS — Google Mobile Services — 谷歌移动服务
- ADB — Android Debug Bridge — 安卓调试桥
- API — Application Programming Interface — 应用程序编程接口
- COSU — Corporate-Owned, Single-Use — 企业自有单用途设备
- OTA — Over-The-Air — 空中升级
- UID — User Identifier — 用户标识符
- AID — Application ID — 应用编号
- DAC — Discretionary Access Control — 自主访问控制
- MAC — Mandatory Access Control — 强制访问控制
- SELinux — Security-Enhanced Linux — 安全增强式 Linux
- UEFI — Unified Extensible Firmware Interface — 统一可扩展固件接口
- SoC — System on Chip — 片上系统
- MQTT — Message Queuing Telemetry Transport — 消息队列遥测传输协议（轻量长连接，知芽设备与服务器通讯用）
- PWA — Progressive Web App — 渐进式网页应用（管理端手机版形态候选）
- VoLTE — Voice over LTE — 基于 LTE 的高清语音通话（电信退网 CDMA 后通话主通道）
- IMS — IP Multimedia Subsystem — IP 多媒体子系统（VoLTE 的核心网架构）
- TLS — Transport Layer Security — 传输层安全协议（通讯加密）
