# 知芽 Zhiya — 项目概述

## 名称

- **中文**：知芽 —— "知识的嫩芽"。孩子是芽，产品是土壤、阳光和园丁。
- **英文**：Zhiya（拼音出海路线，好读、好注册）。
- **Slogan**：一芽一世界。

## 愿景

一条龙打造儿童学习专用设备：**自己做手机硬件 → 自己编译 Android 系统 → 烧录自己的系统 → 安装自己的学习机软件**，小孩拿到手只能使用学习内容，无法用作普通手机。

意象对照：硬件是"根"，系统是"茎"，应用是"叶"，开出的"花"是孩子的成长。

## 阶段规划

| 阶段 | 目标 | 产物落点 |
|---|---|---|
| P0 旧机验证 | 用现有旧手机刷机 + Device Owner 方案验证学习机模式跑通 | `docs/`、`flashing/`、`app/` |
| P1 定制系统 | fork LineageOS，自编译系统：换开机 logo、预装学习机 APP、默认 Device Owner 策略 | `system/`、`flashing/` |
| P2 自研硬件 | 选型 SoC / 公板方案，打样属于自己的硬件 | `hardware/` |
