# 学习机实现方案（Device Owner + 锁任务模式）

## 路线

不走"拦截 Home 键"野路子，用 Android 官方企业单用途设备（COSU）方案：**Device Owner + Lock Task Mode**。

## 实施步骤

1. **设为设备所有者**：恢复出厂设置，开机向导不登录任何账号，连接电脑执行：
   `adb shell dpm set-device-owner com.你的包名/.AdminReceiver`
2. **进入锁任务模式**：`setLockTaskPackages()` 登记自己包名 → `startLockTask()`。此后 Home / 最近任务键被系统接管，按 Home 只回你的 APP，调不出桌面。
3. **沉浸式全屏**：`IMMERSIVE_STICKY` + 全屏主题，隐藏导航栏；`setStatusBarDisabled()` 禁状态栏展开；`setKeyguardDisabled()` 去锁屏。
4. **加用户限制**（`addUserRestriction`，防绕过核心）：
   - `DISALLOW_SAFE_BOOT`：禁安全模式（否则重启进安全模式可绕过一切）
   - `DISALLOW_FACTORY_RESET`：禁恢复出厂
   - `DISALLOW_DEBUGGING_FEATURES`：禁 USB 调试，杜绝连电脑破解
   - `DISALLOW_ADD_USER` / `DISALLOW_UNINSTALL_APPS`：禁多用户、禁卸载
5. **常驻保活**：前台 Service + 开机自启；锁任务模式下 APP 被杀会被系统拉回前台。
6. **家长出口**：隐藏手势（如连点角落 5 次）+ 密码 → `stopLockTask()` 进维护模式，可更新 APP、装学习资料。
7. **内容层**：课程 / 阅读 / 练习模块、番茄钟、作息时间表（如 21 点后只留阅读）、用眼时长提醒。

## 防绕过检查清单

- [ ] 安全模式（已禁）
- [ ] recovery 双清：重锁 bootloader（`fastboot flashing lock`）大幅缓解
- [ ] USB 调试（已禁）
- [ ] 联网后装其他应用：不预装浏览器/应用商店，或网络白名单
- [ ] 换卡、换账号：开机向导不登录账号，Device Owner 与账号无关

## 备选轻量方案

旧机解不了锁时：系统自带"屏幕固定"（Screen Pinning）+ 锁屏密码。长按返回 / 重启可退出，只能防君子，适合先验证产品形态，长期用走 Device Owner。

## APP 更新

自建版本检查接口，或维护时连电脑 adb 安装。预置进 system 分区则做成卸不掉的系统应用（需编译期处理，见 `06-自编译系统指南.md`）。
