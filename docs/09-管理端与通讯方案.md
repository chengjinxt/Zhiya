# 知芽管理端与通讯方案（09）

- 日期：2026-10-22
- 状态：待用户拍板
- 与 docs/08 的关系：08 定版为「定位走短信指令、v1 不建服务器」。本方案应 2026-10-22 新需求（家长管理端登录看位置）提出服务器化路线；若确认，08 的定位部分按本方案改版，短信指令保留为备用通道。

## 1. 需求拆解

- 设备端插国内 SIM（移动/联通/电信），能打电话、收短信（儿童手表式基础通讯）
- 基站定位，孩子无感知：界面无定位入口/图标，不弹定位相关提示
- 家长管理端：手机优先，登录后看设备位置；PC 端后补

## 2. 设备端

### 2.1 SIM 与通话/短信

- MIX 2 为全网通硬件，三网卡均可插；自研 APP 任默认拨号器 + 默认短信应用（Device Owner 可指定角色），通话白名单在来电服务层拦截（沿用 08 定版：仅白名单双向通话）
- **第一风险：电信 VoLTE。** 电信已大面积退网 CDMA，通话主要靠 VoLTE（IMS）；LineageOS 对电信 IMS 的支持不稳定。刷机后第一件事实测：电信卡 VoLTE 通话 + 短信收发。测不过的备选：先用联通/移动卡验证整条链路，电信单独立项排查。

### 2.2 隐蔽定位

- 无定位 UI、无定位入口；定位全部由后台服务完成，两条数据路：
  1. **网络定位**：LocationManager 的 NETWORK_PROVIDER（基站 + WiFi 融合），不开 GPS，精度约 50m–1km，基站密的市区更好
  2. **原始基站上报**：TelephonyManager 读取当前小区 MCC/MNC/TAC/CID 一并上报，服务端用基站库换算坐标兜底（设备侧网络定位失败时仍有粗位置）
- **残留问题（P0 阶段如实标注）**：Android 12+ 在应用获取定位时，状态栏会短暂出现系统定位标记，这是系统级指示，应用层抹不掉。缓解：只在家长请求时和低频周期定位，出现时间短；根治在自编译系统阶段：定位做成系统服务并从系统界面层去掉该指示。

### 2.3 保活与静默

- Device Owner 将本应用加入电池优化白名单；长连接由前台服务维持，通知栏只挂普通文案（如「知芽服务运行中」），不提定位
- 自编译系统阶段改为系统服务：无通知、无图标

## 3. 通讯链路（核心）

```
知芽设备 ⇄ MQTT over TLS ⇄ 服务器 ⇄ HTTPS ⇄ 家长管理端
备用通道：家长手机 ⇄ SMS 指令 ⇄ 知芽设备（沿用 08 设计）
```

- **主通道 MQTT**：轻量长连接，不依赖谷歌服务/推送，省电。主题划分：上行（位置/状态/电量上报）、下行（命令：立即定位、白名单更新、响铃寻机等）、遗嘱消息判离线
- **上报策略**：家长点「立即定位」→ 服务器经 MQTT 下发 → 设备定位后回传；平时低频心跳（5–10 分钟）+ 显著移动时上报；单次数据几百字节，普通流量卡够用
- **备用通道 SMS**：无数据连接或服务器不可达时，家长发口令短信 → 设备回坐标 + 地图链接。双通道互备，管理端不可用时仍能定位
- **坐标系**：设备上报 WGS-84 原始坐标；管理端用高德地图展示时由服务端统一转 GCJ-02，避免国内地图偏移
- **安全**：全程 TLS；每台设备独立令牌；首次激活在家长维护模式出二维码，管理端扫码绑定到家长账号；位置数据建议只保留 30 天

## 4. 服务器

- 组件：MQTT 代理（EMQX 或 Mosquitto）+ REST 接口 + 数据库（MVP 用 SQLite 或 PostgreSQL 均可）
- 部署：MVP 先上云轻量服务器（国内节点，几十元/月，家长手机随时可连）；域名与备案后续补。家里 Windows 机 + 内网只适合开发调试，家长手机在外网连不上，不作正式方案
- 账号：家长账号（手机号 + 密码），令牌式登录态；一账号可绑多台设备，一台设备只绑一个主账号

## 5. 管理端（家长手机）

形态对比：

- **移动 Web / PWA（推荐 MVP）**：一套代码全平台（家长用 iPhone 也行），高德地图网页接口显示位置，开发最快；PC 端就是同一套网页的桌面布局，后补几乎零成本
- **Android 原生**：体验最好、与设备端共享 Kotlin 代码；但家长若用 iPhone 需再做一套
- **微信小程序**：免安装，但定位类目审核与资质麻烦，不推荐

功能清单（MVP）：

- 登录、设备列表与在线/离线状态
- 地图页：当前位置 + 精度圈 + 更新时间，一键「立即定位」
- 历史轨迹：按天回放
- 消息提醒：SOS、低电量、长时间离线
- 远程设置：通话白名单号码增删（放管理端维护，比在设备上方便）、定位频率

后续：电子围栏、轨迹导出、PC 管理后台。

## 6. 分期

- **第 0 步（与刷机并行）**：电信卡实测——MIX 2 + LineageOS 上测电信 VoLTE 通话/短信，不过关先换运营商卡验证链路
- **P0**：按 08 定版先落地（通话白名单 + 短信 + SMS 指令定位），蜂窝能力先跑通
- **P1**：服务器 + MQTT + 管理端 Web MVP（实时位置/轨迹/立即定位/白名单远程管理）
