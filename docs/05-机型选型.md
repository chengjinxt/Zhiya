# 机型选型（国产）

## 推荐

**首选一加（OnePlus）**
- 解锁无需申请，fastboot 一条命令直接解。
- LineageOS 官方支持机型最多（一加 7～15 全系列有维护者），XDA 资料最全。
- 二手一加 8/9 便宜，骁龙 865/888 性能过剩。

**次选小米 / Redmi**
- 官方线刷包最全（MiFlash + fastboot 包），救砖容易。
- Redmi Note 8/9/10、POCO F3 有 LineageOS 官方包。
- 注意：HyperOS 国行机解锁门槛高（社区等级、一年一台、部分机型已无法解锁）——**只收 MIUI 时代老机型，不碰 HyperOS 新机**。

**备选 realme**
- 部分机型可解锁（9/10 Pro、GT7 Pro、Q5 有官方包）。

## 避雷

- 华为 / 荣耀：bootloader 不再开放。
- OPPO / vivo / iQOO：基本不给解锁。
- 二手注意：无账号锁、无运营商定制；小米机解锁前先退出小米账号。

## LineageOS 版本建议

- 24.0 基于 Android 17（2026-10 刚发布），老机型建议用 22.x/23.x 稳定分支。
- 只刷 wiki.lineageos.org 上的官方包，不碰来路不明的修改版。
- LineageOS 默认不带 GMS（谷歌服务）——对学习机是优点，少一个分心入口。
